# Kinetix Website - Final
This folder contains the complete, interactive frontend for the Kinetix energy drink launch.

**Updates Included:**
- Added a functional dark/light mode toggle.
- Upgraded the CSS to a modern, high-contrast, "cyberpunk" style.
- Replaced local image placeholders with high-quality web-hosted images (via Unsplash) so they render immediately.
- Added a new image gallery to the Home page.
- Expanded the ingredients list table.
- Added interactive hover effects to buttons and images.

**Files:**
- `index.html` (Home)
- `about.html` (About)
- `contact.html` (Contact)
- `styles.css` (CSS)
- `script.js` (JavaScript)
